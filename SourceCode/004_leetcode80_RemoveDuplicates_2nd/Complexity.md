# ⚡ Time Complexity
## ✅ O(n)
Why? We traverse the array once
Each element is processed exactly one time
We either skip it or place it at index k

# 🧠 Space Complexity
## ✅ O(1) (Constant extra space)
Why? We modify the array in-place
We only use a few variables:

i → traversal pointer
k → write position tracker

👉 No extra array or data structure is used
