# ⚡ Time Complexity

## ✅ O(n)

Why?

We traverse the string only once for extracting words.

Each character is visited at most once.

Breakdown:
Traverse string → O(n)
Store words → O(n)
Reverse printing → O(n)

## 👉 Total work: O(n)

# 🧠 Space Complexity
C Version

## ✅ O(n)

Why?

We store all words separately inside array.

Extra memory depends on input size.
