# ⚡ Time Complexity
## ✅ O(n)
Why?
We traverse the array only once using a single loop.
for(int i = 0; i < n; i++)
Each operation inside the loop:


subtraction


addition


comparison


takes constant time O(1).
👉 Overall complexity = O(n)

totalGascurrentGasstartdiff
