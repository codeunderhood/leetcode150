# ⚡ Time Complexity
## ✅ O(n)
Why?
We traverse the array once
For each element:
We check if it is equal to val
If not, we copy it to position k
Key point:
Each element is visited exactly one time
# 🧠 Space Complexity
## ✅ O(1) (Constant extra space)
Why?
We modify the array in-place
We only use a few variables:
i → traversal pointer
k → position tracker

👉 No extra arrays or data structures are used
