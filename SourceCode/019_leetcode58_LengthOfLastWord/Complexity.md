# ⚡ Time Complexity ✅ O(n)

Why?

In worst case, we may traverse the whole string once.

Breakdown:

Skip trailing spaces → O(n)
Count last word → O(n)

But total traversal is still: O(n)

## 👉 Each character is visited at most once.

# 🧠 Space Complexity ✅ O(1) (Constant extra space)

Why?

No extra data structure is used.

We only use:

i
count

These are constant variables.

## 👉 Extra space does not depend on input size.
