# ⚡ Time Complexity ✅ O(n)

Why?

We traverse the Roman numeral string only once.

Breakdown:

Value lookup for each character → O(1)
Single loop traversal → O(n)

Each character is processed exactly one time.

👉 Total work: O(n)

# 🧠 Space Complexity ✅ O(1) (Constant extra space)

Why?

No extra data structure is used that grows with input size.

We only use:

result
current
next
loop variable i

👉 Since only fixed variables are used, extra space remains constant.
