# ⚡ Time Complexity ✅ O(1)

Why?

Roman numeral system has only 13 fixed symbols/values.

The loop always runs at most a constant number of times.

Breakdown:

Traverse Roman values array → O(13)
Inner while loop runs limited times (maximum Roman length is small)

## 👉 Total work: O(1)

# 🧠 Space Complexity ✅ O(1) (Constant extra space)

Why?

We only use:

fixed arrays of Roman values
fixed arrays of symbols
result string

## No extra space grows with input size.
